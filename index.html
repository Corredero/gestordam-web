Bienvenido a GestorDAM

Una aplicación de escritorio desarrollada en Java para visualizar y modificar indicadores de forma sencilla e intuitiva.

Descargar para Windows

¿Qué ofrece GestorDAM?

Interfaz intuitiva

Diseño sencillo que facilita la interacción con los elementos de la aplicación.

Indicador visual

Permite visualizar el valor de un indicador gráfico y modificarlo mediante controles.

Instalación sencilla

Incluye un instalador para facilitar la instalación y ejecución en Windows.

Documentación

Consulta las instrucciones de instalación y la información de la aplicación.
