# GestorDAM

**Versión:** 1.0.0

## Descripción
GestorDAM es una aplicación de escritorio desarrollada en Java utilizando Swing. Permite visualizar y modificar el valor de un indicador gráfico mediante una interfaz sencilla e intuitiva.

## Requisitos
- Sistema operativo Windows.
- No es necesario tener Java instalado, ya que la distribución incluye su propio entorno de ejecución.

## Instalación
1. Descargar el archivo GestorDAM-Setup.exe.
2. Ejecutar el instalador.
3. Seguir las instrucciones del asistente.
4. Una vez finalizada la instalación, iniciar GestorDAM desde el acceso directo creado.

## Desinstalación
La aplicación puede desinstalarse desde la sección de aplicaciones instaladas de Windows.

## Firma digital
El archivo JAR de la aplicación ha sido firmado mediante un certificado de prueba autofirmado. Esta firma permite comprobar su integridad, pero no equivale a una certificación de confianza emitida por una autoridad reconocida.
